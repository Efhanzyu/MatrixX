CCR Analysis

Computation-to-Communication Ratio (CCR) & Teori Skalabilitas

Dalam perkalian matriks terdistribusi, kompleksitas komputasi adalah O(N³) sedangkan kompleksitas transfer data (komunikasi) adalah O(N²). Rasio komputasi terhadap komunikasi didefinisikan sebagai:

CCR = O(N³) / O(N²) = O(N)
N = 512 × 512
CCR = 2.60x (Comm-Bound)
Overhead komunikasi: 27.8%
N = 1024 × 1024
CCR = 4.53x
Overhead komunikasi: 18.1%
N = 2048 × 2048
CCR = 7.97x
Overhead komunikasi: 11.2%
N = 4096 × 4096
CCR = 16.94x (Compute-Bound)
Overhead komunikasi: hanya 5.6%

*Kesimpulan Ilmiah:* Pada matriks besar ($N=4096$), penalti komunikasi tereduksi drastis menjadi hanya 5.6%, sehingga sistem mencapai efisiensi paralel tertinggi dan membuktikan bahwa arsitektur cluster sangat efektif untuk *large-scale matrix workloads*.
